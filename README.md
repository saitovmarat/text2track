# text2track
Combining tracking and detection, CLIP and VLM models to track people by their description

## Dataset
The tracker is evaluated on [MOT17](https://motchallenge.net/data/MOT17/), provided by MOTChallenge. 
The training sequences, public detections, and ground-truth annotations can be downloaded from the benchmark page.

MOTChallenge distributes the dataset under [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/).
